# Blacksite showcases

Each route is a small game scene composed from published Blacksite package exports. The default overlay contains a title, one sentence, controls, and a compact performance line. Developer telemetry is behind **Dev**. The source excerpt on each page is imported from that scene's source file.

| Scene | Direction and game facing tech | Package work | Assets |
| --- | --- | --- | --- |
| **Movement · The Yard** | One ALS operator in a sunlit training courtyard. Steps, a ramp, and ledges make walk, sprint, crouch, mantle, roll, ragdoll and FPP/TPP legible. Public `als-ue5-r3f` Character and Camera exports provide movement; `@blacksite/subject-fpp/arms` provides the FPP viewmodel. | The current `templates/prototype-kits/als-tpp/mode.tsx` supplies only a grid and is not reused. No ALS mechanics are trapped in that template; its published component exports already cover the scene. | ALS MIT character and animation bundle, already shipped by `vendor/als-web/public/assets`; procedural architecture and materials. No additional downloads. |
| **Demolition · Last Light** | A concrete frame on a golden hour construction site. Orbit, place charges, detonate, or walk in with explosive, cannonball, sledge and cutter. Worker simulation through `DestructionSession`, `DestructionRenderer`, and `CascadeWalkClient`. | The lab's `PhysicsClient` in `packages/cascade/src/large-structure-demo.ts` duplicates the already public `DestructionSession`; the showcase uses that package API. Expose the `packages/destruction-testkit/src/scale-frame.ts` authored fixture through a public `@blacksite/cascade/showcase-frame` factory and test its manifest. Keep rendering and interaction game owned. | Procedural frame, site slabs, fencing, stacked supplies, signage and dust. No downloaded assets. |
| **Firing Range · Sightline** | FPP arms, rifle and pistol, spaced reactive targets, ADS, recoil and reload. `@blacksite/subject-fpp` plus `@blacksite/armory`. | Move range target spawning and hit reaction from `site/src/demos/fpp.tsx` / `templates/prototype-kits/fpp/mode.tsx` into Armory if any reusable logic is currently confined there. | Blacksite arms and ALS MIT weapon assets; procedural targets and range. |
| **Squad AI · Breach** | Four Warden agents clear a compact courtyard and room. Optional intent annotations only when requested. | Extract the worker orchestration and presentation contract from `packages/client-r3f/src/App.tsx` and `Scene.tsx` into Warden's public runtime and `@blacksite/warden-react`; test command and snapshot boundaries. | Procedural walls, cover and figures. |
| **Arena · Relay Room** | Two local peers share a loopback Relay room, each with a readable view of the same arena. Build after remote locomotion work lands. | `site/src/demos/mp.tsx` becomes composition code over `@blacksite/relay` and `@blacksite/subject`; move any missing peer lifecycle into owning packages, with tests. Merge `btn0s/blacksite-remote-locomotion` first. | ALS MIT character and arms; procedural arena. |

Movement and Demolition are the first checkpoint. The landing page leads with showcase cards; old lab routes remain under **Labs** for developer inspection. Each showcase owns a lazy scene chunk. Scene geometry is procedural, so there is no texture or mesh compression task at this checkpoint. Any later downloaded file needs an adjacent source and license entry and should be compressed before shipping.
