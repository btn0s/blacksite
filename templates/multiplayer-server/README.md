# Multiplayer server

`pnpm dev` runs this Colyseus match server and Vite together. Play connects through the same-origin `/relay` path; Vite proxies HTTP matchmaking and WebSocket upgrades to the local server on port 2567. The Offline button starts a loopback room using the same match policy. A static demo can mount `LoopbackSplitView` from `@blacksite/subject`; it calls `createLoopbackRoom()` and renders two local players in separate canvases, with no server. A second browser tab joins the same online room. The local camera defaults to FPP, V switches to TPP while the canvas has focus even without pointer lock, and `cameraMode="fpp"` or `cameraMode="tpp"` locks it; remote players always render ALS bodies. The starter arms are simple procedural meshes included in the template; replace them with game art when ready. Vite accepts `*.getbb.app` and `*.ts.net` preview hosts by default. Set `VITE_ALLOWED_HOSTS=preview.example.com,other.example.com` before `pnpm dev` to allow additional hostnames. Set `VITE_RELAY_URL` to a full Colyseus endpoint when the server uses another origin or path.

For deployment, follow Blacksite's `skills/blacksite/references/process.md` (Ship) (under `vendor/blacksite/` in this scaffold): serve the static client with a Cloudflare Worker and route `/relay` through Workers VPC → Tunnel → Docker Colyseus. Keep the public path and room endpoint aligned. Relay v0 does not add production deployment files, interest management, or lag compensation.
