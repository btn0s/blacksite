# Multiplayer server

`pnpm dev` runs this Colyseus match server and Vite together. Play connects through the same-origin `/relay` path; Vite proxies HTTP matchmaking and WebSocket upgrades to the local server on port 2567. When the room is unreachable, Play falls back to a loopback room with the same match policy; a static demo uses `createLoopbackRoom()` with no server. A second browser tab joins the same online room. The local player is the Character Controller with `views: ['arms', 'shoulder']` inside `Replication`: it starts in first person with found arms, V switches to the shoulder view even without pointer lock, and a single entry in `views` locks it. Remote players always render ALS bodies holding their current weapon. Vite accepts `*.getbb.app` and `*.ts.net` preview hosts by default. Set `VITE_ALLOWED_HOSTS=preview.example.com,other.example.com` before `pnpm dev` to allow additional hostnames. Set `VITE_RELAY_URL` to a full Colyseus endpoint when the server uses another origin or path.

For deployment, follow Blacksite's `skills/blacksite/references/process.md` (Ship) (under `vendor/blacksite/` in this scaffold): serve the static client with a Cloudflare Worker and route `/relay` through Workers VPC → Tunnel → Docker Colyseus. Keep the public path and room endpoint aligned. Relay v0 does not add production deployment files, interest management, or lag compensation.
