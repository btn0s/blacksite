# Blacksite agent map

For anything game-related, read `skills/blacksite/SKILL.md` and follow it; without a specific task, ask its opening question. It is the only skill. Its workflow, craft and building-block references live in `skills/blacksite/references/`. Ask one design question at a time and preserve the user's choices. Assets are optional; use indexed metadata through `blacksite assets list|search|suggest` when available. The user runs optional `blacksite assets login` in their own terminal.

`cli/` contains deterministic tools, `templates/game-shell/` the generated game, `packages/` reusable systems, and `chambers/` playable proof scenes. Read `CONTEXT.md` when naming a system or platform package: Subject, Armory, Warden, and Cascade are current systems; platform packages keep plain names. Install from the repository with `install.sh` or `install.ps1`. Run `node scripts/check-skills.mjs`, `node scripts/generate-kit.mjs`, and the relevant gate before committing. Never name another game engine in the skill.

Never read credential stores or any file whose name contains login, token, secret, key, or credential; use the Blacksite CLI, which never prints credentials. Never copy purchased assets into this repository. Use caret ranges at latest published dependency versions. Do not add code comments. Keep external game repositories untouched. Do not run headed browsers or push/publish without explicit authorization.
