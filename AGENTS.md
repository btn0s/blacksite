# Blacksite agent map

If invoked without a specific task, read `skills/start/SKILL.md` and ask **What would you like to do?** with its seven choices. For a game idea, use `skills/make-game/SKILL.md`. The phase skills live in `skills/`: design-game, setup-project, build-prototype, combine-prototypes, optimize-game, and ship-game. The shared references are game-architecture, blacksite-kit, and game-assets. Ask one design question at a time and preserve the user's choices. Assets are optional; use indexed metadata through `blacksite assets list|search|suggest` when available. The user runs optional `blacksite assets login` in their own terminal.

`cli/` contains deterministic tools, `templates/game-shell/` the generated game, `packages/` reusable systems, and `chambers/` playable proof scenes. Read `CONTEXT.md` when naming a system or platform package: Subject, Armory, Warden, and Cascade are current systems; platform packages keep plain names. Install from the repository with `install.sh` or `install.ps1`. Run `node scripts/check-skills.mjs`, `node scripts/generate-kit.mjs`, and the relevant gate before committing.

Never read credential stores or any file whose name contains login, token, secret, key, or credential; use the Blacksite CLI, which never prints credentials. Never copy purchased assets into this repository. Use caret ranges at latest published dependency versions. Do not add code comments. Keep external game repositories untouched. Do not run headed browsers or push/publish without explicit authorization.
