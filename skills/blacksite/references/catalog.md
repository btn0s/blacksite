# Blacksite catalog

Every profile, prototype kit, system, package and command in Blacksite, generated by the `blacksite catalog` command on release. Run `blacksite catalog --json` for the live list. Read `architecture.md` before wiring systems, and `building-blocks.md` before wiring any block.

## Tools

| Command | Use when |
| --- | --- |
| `blacksite install` | Configure agent skills |
| `blacksite doctor` | Check prerequisites |
| `blacksite catalog` | Inspect the current kit |
| `blacksite scaffold` | Create a game shell |
| `blacksite new` | Create a game and add selected assets |
| `blacksite budget` | Check performance limits |
| `blacksite check` | Measure frame time, hitches, pop-in, feel and audio, and capture critic views |
| `blacksite assets` | Optional owned asset discovery and install |
| `blacksite prototype` | Create, list, and promote isolated modes |
| `blacksite architecture` | Print the ownership reference |
| `blacksite update` | Refresh installed tools |
