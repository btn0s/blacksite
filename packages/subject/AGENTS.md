# Subject

Purpose: the one Character Controller for every character game, built on the ALS character (`DESIGN.md`). `createCharacterController({ views })` makes the handle; `<CharacterController controller>` mounts the body, camera and arms inside `<Physics>`; `CharacterOverlay` draws touch controls and device prompts. `setPaused` releases input and reports `paused`; the session owns pause and time. For single player, `useLocalSession` pauses on the pause action and on pointer unlock, and stops the frame loop and its `now()`; a game with its own menus passes its pause state to `setPaused`.

Pick the views: `['arms']` for first person, `['shoulder']` or `['shoulder', 'head']` for third person, `['arms', 'shoulder']` for a switchable view. Weapons run through Armory; the default weapon queries cast into the Rapier world and skip the player's own body, and a game passes `queries` to use its own. For multiplayer, mount `<Replication connection controller>` instead of `<CharacterController>`: it sends moves and shots through `@blacksite/relay`, applies server spawns, deaths and revives, and draws other players as ALS remote bodies. The server stays authoritative for hits.
