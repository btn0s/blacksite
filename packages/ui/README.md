# @blacksite/ui

Shared game UI with stock shadcn base-lyra components, Base UI, Tailwind CSS v4, and the neutral token set. Files in `src/components` and `src/hooks/use-mobile.ts` are generated by the shadcn CLI. Keep them stock so `shadcn add` and upgrades can replace them cleanly. Game palettes, typography, and decorative treatments belong in games.

The package exports source. Add Blacksite as a recursive Git submodule, list `vendor/blacksite/packages/ui` in the game's pnpm workspace, and declare `"@blacksite/ui": "workspace:*"`.

## Styling and components

Import the neutral base stylesheet. Console games also import the separate behavior stylesheet after it and mount `ConsoleScope` once at the app shell.

```tsx
import "@blacksite/ui/globals.css"
import "@blacksite/ui/console.css"
import { ConsoleScope } from "@blacksite/ui"

export function App() {
  return <ConsoleScope><main>Game UI</main></ConsoleScope>
}
```

`ConsoleScope` sets `data-console-ui` on the document root and gives interactive controls `tabIndex=-1`, including controls rendered through portals. It watches newly mounted controls and Base UI tab index changes. `console.css` removes focus outlines, provides 44 px minimum targets, and styles `data-console-selected`, `aria-current`, and `data-controller-editing` using the neutral `--primary` token. Games can set `--console-selection` for a different selection color. An explicit `data-console-tabstop` attribute opts a control out of the tab default.

Import components through source subpaths such as `@blacksite/ui/components/button`, or from the package root. `cn` is available at `@blacksite/ui/lib/utils`. Import `ConsoleSelect` and `ConsoleSlider` from `@blacksite/ui/console/console-field`. Their `controller-edit`, `controller-adjust`, and `controller-cancel` event shapes match the current `@blacksite/input` implementation; this branch retains a local event map until the input package is merged. `controller-adjust` uses a numeric `CustomEvent.detail`. `Toaster` uses `next-themes`, so mount a `ThemeProvider` in apps that use it.

In each game app's `components.json`, point `tailwind.css` at the package's `src/styles/globals.css` and set `aliases.ui` to `@blacksite/ui/components`. For an app at `apps/web` with Blacksite at `vendor/blacksite`, the CSS path is `../../vendor/blacksite/packages/ui/src/styles/globals.css`. Add an `@source` directive in the game's stylesheet for its own source directory; the package stylesheet already scans its own `src` directory.

To add or upgrade a stock component, run this from the Blacksite root:

```sh
pnpm --filter @blacksite/ui exec shadcn add <component> --yes --overwrite
```

The CLI uses `packages/ui/components.json` and writes to `packages/ui/src/components`. Add its export to `src/index.ts`, then run typecheck and the focused UI tests. Keep console-specific behavior in `src/console` and `src/styles/console.css`.

## GameFrame

`GameFrame` fills its parent and centers a fixed-aspect stage. The default ratio is `"16/9"` and default fit is `"contain"`, leaving plain bars where needed. `fit="cover"` fills the parent and crops the stage. Set `--game-frame-bar` on the parent to choose the bar color; it defaults to black. `GameFrame.SafeArea` places HUD content inside the larger of CSS `env(safe-area-inset-*)` and the host-provided `--bleed-t/r/b/l` offsets on each side.

```tsx
import { Canvas } from "@react-three/fiber"
import { GameFrame, useGameFrame } from "@blacksite/ui"

function Hud() {
  const { width, height, scale } = useGameFrame()
  return <div>{`${Math.round(width)} × ${Math.round(height)} at ${scale.toFixed(2)}×`}</div>
}

export function Game() {
  return (
    <div style={{ width: "100%", height: "100vh", "--game-frame-bar": "#111" } as React.CSSProperties}>
      <GameFrame ratio="16/9" fit="contain">
        <Canvas style={{ width: "100%", height: "100%" }} />
        <GameFrame.SafeArea><Hud /></GameFrame.SafeArea>
      </GameFrame>
    </div>
  )
}
```

The hook's `width` and `height` are the stage rectangle in CSS pixels. `scale` is relative to a 1080-pixel design height. `GameFrame` updates on `ResizeObserver` notifications, with no frame-by-frame React updates. Give R3F `Canvas` the stage's full width and height so its drawing buffer follows the stage.
