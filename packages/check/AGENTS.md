# Check

Purpose: headless checks for a Blacksite game. `@blacksite/check` is the browser side: the `window.__blacksite` contract types, `exposeCheck()`, `applyCameraPose()` and `createAudioLog()`. `@blacksite/check/runner` is the Node side behind `blacksite check`: it drives system Chrome through playwright-core with the GPU on and writes `report.json` and PNGs for perf, hitch, pop, feel, critic and audio. The contract and how to read results are documented in `skills/blacksite/references/verify.md`. The runner is plain ESM so the CLI runs it without a build; keep the contract in `src/index.ts` and the runner in `src/runner.mjs` in step. The z-fighting modules live in `src/zfight/`: `lint.mjs` is the static lint (pure ESM, no DOM, shared by the CLI, the page and tests), `probe.mjs`, `analyze.mjs` and `session.mjs` run inside the page and are concatenated by `page-script.mjs`, and `runtime.mjs` is the Node side of the `zfight` check. Keep functions in the page-side modules uniquely named, because they are bundled into one scope.
