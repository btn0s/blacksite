# Notices

`src/physical.ts` ports techniques from web-ocean by Maksymilian Dendura (https://github.com/Noniv/web-ocean): the Hillaire transmittance, multiple-scattering and sky-view lookup tables, the domain-warped cloud layer with footprint-faded octaves and analytic edge antialiasing, and its cloud lighting. The code was rewritten in GLSL for three.js; constants and structure follow the original.
